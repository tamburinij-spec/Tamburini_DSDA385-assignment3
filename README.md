# NLP Assignment

## Project Overview
This project implements two NLP tasks:
1. Text Generation
2. Machine Translation

## Models Used
- LSTM (Task 1)
- GRU (Task 2)

## Embeddings
- One-hot encoding
- Pretrained GloVe embeddings

## Datasets
- Shakespeare dataset (text generation)
- Small English-Spanish dataset (translation)

## Results
- Loss used for text generation
- Translation accuracy qualitatively evaluated

## Comparison
LSTM performed better for sequence prediction.
GRU was faster but slightly less expressive.

## Challenges
- Handling variable sequence lengths
- Limited dataset size

## Limitations
- Small datasets
- No attention mechanism

## Future Work
- Add Transformer models
- Use larger datasets
